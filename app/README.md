# App móvil de Lüp

Carpeta reservada para el código de la app móvil (React Native / Expo / Flutter).

La app puede consumir la API REST del backend Django:

- `GET /api/productos/` — ofertas disponibles (con comercio, dirección, precios y % de descuento).
- `GET /api/productos/<id>/` — detalle de una oferta.
