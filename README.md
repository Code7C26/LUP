# ¿Qué es Lüp?

Lüp es una plataforma inteligente diseñada para reducir el desperdicio alimentario mediante la gestión eficiente de excedentes de comercios. La aplicación conecta supermercados, panaderías, restaurantes y otros negocios con consumidores y organizaciones sociales, permitiendo que los alimentos próximos a vencer encuentren una segunda oportunidad antes de convertirse en residuos.

Nuestro objetivo es generar un impacto ambiental, social y económico positivo, promoviendo un modelo basado en la economía circular y el consumo responsable.

---

# Objetivos

- 🌱 Reducir el desperdicio alimentario.
- 🍽️ Dar una segunda oportunidad a alimentos aptos para el consumo.
- 💰 Disminuir las pérdidas económicas de los comercios.
- ❤️ Facilitar el acceso a alimentos a menor costo.
- 🤝 Favorecer la donación responsable a organizaciones sociales.
- 🤖 Incorporar Inteligencia Artificial para optimizar la gestión de excedentes.

---

# Funcionalidades

## 🏪 Comercios

- Publicar productos próximos a vencer.
- Aplicar descuentos inteligentes.
- Gestionar el stock de excedentes.
- Visualizar estadísticas e impacto generado.

## 👤 Consumidores

- Encontrar alimentos con descuento.
- Buscar comercios cercanos.
- Reservar productos desde la aplicación.
- Historial de compras.

## ❤️ Organizaciones

- Solicitar alimentos donados.
- Gestionar donaciones.
- Historial de entregas.

## 🤖 Inteligencia Artificial

- Reconocimiento automático de productos.
- Completar información mediante imágenes.
- Recomendar descuentos según la proximidad al vencimiento.
- Priorizar productos con mayor urgencia.
- Generar estadísticas e indicadores ambientales.
